# 자재코드 표준화 및 검색 도구 — Netlify 배포판

## 변경 내용
- 기존 HTML 화면·엑셀 처리·AI 프롬프트·사양서 기능을 유지했습니다.
- 브라우저에서 Gemini API를 직접 호출하지 않고 `/.netlify/functions/gemini`를 호출합니다.
- API 키는 서버 환경변수 `GEMINI_API_KEY`에서만 읽습니다. **API 키를 HTML에 붙여넣지 마세요.**

## 배포 방법
1. Google AI Studio에서 Gemini API 키를 발급받고, 사용 가능 모델 및 요금·할당량을 확인합니다.
2. Netlify에 사이트를 생성합니다. 이 ZIP을 압축 해제하여 **폴더 전체**를 배포하세요. `index.html`만 업로드하면 서버 함수가 빠집니다.
   - 권장: 이 폴더를 Git 저장소에 올려 Netlify에 연결하고 배포합니다.
   - Netlify의 수동 드래그앤드롭 배포는 Functions 소스 빌드를 지원하지 않을 수 있습니다. 이 경우 Git 연동 또는 Netlify CLI로 배포하세요.
3. Netlify 사이트 설정 → Environment variables에서 `GEMINI_API_KEY`를 추가합니다. Functions에서 접근 가능한 범위로 설정합니다.
4. 필요하면 `GEMINI_MODEL`을 설정합니다. 기본값은 원본 파일의 `gemini-3-flash-preview`입니다. 해당 모델이 계정에서 지원되지 않으면 사용 가능한 모델 ID로 바꾸세요.
5. 환경변수 저장 후 **재배포**하고, 웹사이트에서 '표준화 및 검색 시작'을 테스트합니다.
6. 기존 매뉴얼 다운로드 링크를 사용하려면 `4_표준화가이드북_구매2팀_20211104 (2).pdf` 파일을 `index.html`과 같은 위치에 추가하세요.

## 운영 전 필수 주의
- **이 ZIP은 키를 서버로 옮기는 수정본이지, 로그인/인증이나 강력한 사용자별 속도 제한이 구현된 완전한 운영 서비스는 아닙니다.** 공개 URL을 아는 누구나 AI 요청을 발생시킬 수 있습니다. 30명 배포 전 Netlify 접근 통제, 서버 측 사용자 인증, 속도 제한 및 비용 한도/알림을 별도로 구성하세요.
- Gemini 검색(`google_search`)과 JSON 스키마 응답의 동시 사용 여부는 선택한 모델/API에서 실제 테스트가 필요합니다. 계정·모델에 따라 API 오류가 발생할 수 있습니다.
- 업로드한 엑셀은 브라우저에서 처리되지만 검색 결과 일부 행은 AI 요청 본문에 포함되어 Google API로 전송됩니다. 회사 기밀정보·계약단가·개인정보 취급 정책을 확인하세요.
- AI가 생성한 공구코드, 구매 링크, 단종 여부, 제품 사진은 실제 발주 전에 확인하세요.
- 제품 이미지 URL은 외부 사이트의 접근 정책에 따라 표시되지 않을 수 있습니다.
- 외부 CDN(Tailwind, XLSX, Font Awesome, Google Fonts)을 사용하므로 네트워크 접속이 필요합니다.

## 간단 점검
- 웹사이트가 뜨지만 AI가 실패: Netlify Functions 로그, `GEMINI_API_KEY`, 모델 ID, API 할당량을 확인하세요.
- 404: Netlify Functions가 함께 배포되지 않았을 가능성이 큽니다.
- 매뉴얼 PDF가 다운로드되지 않음: 원본 PDF 파일을 동일 폴더에 추가하세요.
